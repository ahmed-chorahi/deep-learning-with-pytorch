## ▶️ How to run

```bash
cd 05_computer_vision
cd 01_mnist
python mnist.py
```

> 🌐 These lessons download MNIST / Fashion-MNIST the first time you run them, so you need internet once. The data is saved in a `data` folder.

## 💡 Tips

1. Read the lesson `.md` first, then run the `.py` file.
2. Change a number in the code and run it again to see what happens.
3. Finish the **Try It Yourself** and **Quick Questions** parts before moving on.
