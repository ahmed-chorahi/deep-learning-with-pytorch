## ▶️ How to run

```bash
cd 06_projects
cd 01_mnist_project/02_train && python train.py       # 1. train first
cd ../03_predict && python predict.py                 # 2. then predict
```

The same order works for `02_fashion_mnist_project` and `03_simple_classifier`.

> 🌐 The MNIST and Fashion-MNIST projects download their data the first time (internet needed). `03_simple_classifier` makes its own data and works offline.

## 💡 Tips

1. Read the lesson `.md` first, then run the `.py` file.
2. Change a number in the code and run it again to see what happens.
3. Finish the **Try It Yourself** and **Quick Questions** parts before moving on.
